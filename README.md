# 🪨 Rock Paper Scissors Game 🎮

A simple and interactive Rock-Paper-Scissors game built with **HTML**, **CSS**, and **JavaScript**. Challenge the computer, track your score, and enjoy the responsive design with emoji-based gameplay!

---

## 🚀 Features

- 🎮 Play Rock, Paper, or Scissors against the computer
- 📈 Persistent scoreboard with wins, losses, and ties saved via `localStorage`
- 💻 Responsive layout for desktop and mobile screens
- 🎨 Clean UI with styled buttons and emojis
- 🔄 Reset score functionality
- 📝 Real-time DOM manipulation with JavaScript

## 🛠️ Technologies Used

- **LocalStorage** – To store game score between sessions
